# 玩家试玩缺陷修复

以 `ea8ce85` 的实测报告为基线。V38 仍以静态站运行，未改变经典版入口或存档；V38 的报价草稿只在本局内保留。

| 验收问题 | 修复后 |
| --- | --- |
| B01 入口模块出错 | 启动失败可见中文说明和重试按钮。长时间加载也提供可点击的重试。 |
| E01、E10 银行重复提交及校验 | 借贷表单执行一次后清除本次金额。反馈显示实际金额；重新输入可发起下一笔。开局空名和银行金额错误用中文在字段旁提示。 |
| E02、E07、E08、E12 引导与排版 | 关闭或跳出算价后引导落到可用目标，初开小结先显示结果，新报价从顶部打开，返回时恢复条目位置和焦点。本局内重开同一询盘可继续调整草稿。长公司名换行，版本标记有独立空间。 |
| E03、E11 预计利润和现金明细 | 加急等已支付订单费用即时进入预计利润，交付时只核算一次。周小结区分定金、回款、融资、采购和周费用，成交价按实际商品单位。已付款待备货与已交货待收款分别标注。 |
| E04 会话边界 | 创建与离开本局时说明刷新或关页会结束本局。 |
| E05、E06、E09 弱网和报价提示 | 预留商品图、头像和漫画空间。失图能看到替代说明，手动展开的漫画可重试。正余额和资金缺口的文案及颜色分开。 |
| E13、E14 决策和生活反馈 | 受影响订单和应收标明对象。会改变工期的选项提供预计交付和回款日期；包装线邀请说明期限与优惠。花市结果展示发生后的故事，而不是重复预告。 |
