# 第二期：扩张与贸易风险

- 四位助理进入人才市场，加入业务、跟单、财务三个岗位、四周人才市场刷新、负责人的容量、周薪与提成、同行挖角。
- 三阶认证逐步开放国际市场和大额采购。通过展会或重点客户介绍进入新市场；各地有不同币种、船期、关税、品类和信用分布。
- 外币报价会进入订单和应收；收款使用当周汇率，保理即时买断应收，信用证及信用保险改变回款风险，出口退税按周到账并计入预测。
- 汇率、运价、原料、消费与同行经营按周变化。加入贸易事件、同行收购、重点客户复购及既有漫画。
