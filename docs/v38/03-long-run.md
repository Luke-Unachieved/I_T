# 第三期：长期经营与上市

- 五个时代剧本、三种出身和三档难度，改变起步资金、市场、订单风险或竞争。时代事件在约定周随结算推进。
- 五种产业布局各可升三级。自有仓库支持备货，工厂降低对应品类的采购成本，海外仓缩短本地交付，自有品牌支持自主定价，跨境电商带来每周经营收入。
- 公司页显示年度目标、滚动营收与估值、全国排名、投资与上市条件、成就、大事记和企业传记。完成上市后还能继续经营。
- 办公室港口随在途货物、海外市场与仓库变化。下班后可以买卖房车、用房产增授信，或花钱恢复精力。

## 复测

1. 用 `npm start` 打开游戏，切换时代、出身和难度，比较开局数值与公司事件。
2. 在公司页查看产业链和上市三步的条件。开通仓库后到订单页备货；开通品牌后可在报价表按件输入单价。已有海外仓的市场会显示本地交付。
3. 到下班页购买房产、办理抵押，再去公司银行查看授信；安排出游可看到精力变化和原版插画。
4. `npm run check` 跑功能验收；`V38_BROWSER=1 npm run check` 加跑 Chromium 界面验收。

所有改动在 `v38-weekly` 分支。上线前由仓库主人更新发布清单并合入 GitHub Pages。

## 验收记录

- Chromium 使用 1440px 桌面与 390×844 手机视口检查产业投入、备货、品牌报价、上市、港口与下班生活。上市按钮流程从符合申请条件的定向测试场景开始。
- `node tests/functional-play.mjs 520` 从「2001 入世红利 / 工厂二代 / 轻松」开局，通过公开游戏动作结算 520 周。第 105 周完成上市，此后继续经营，累计交付 974 单。该脚本验证一条可行路线，其中的报价策略只是复测用例。
