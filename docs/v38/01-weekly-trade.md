# 第一期：国内周经营

- 公司名、四位助理和五步引导；开头三周保留原版客户及美术。之后每周生成国内询盘。
- 计算采购、运费、单价、账期、中单率和垫资，周末揭晓竞争结果。订单自动采购、生产、运输与收款，有延期、清仓、催收、诉讼、授信和破产。
- 办公室、询盘、订单、公司、下班五页；现金预测有实际排期和「全部中单」假设两条路径。每年 52 周结算。
- `classic.html` 和 `legacy-game.html` 保持 V37 与旧版入口内容。V38 本局进度存在页面内存。

## 复测

1. `npm start` 后开局，查看米拉的询盘，报价比例设为 80%，提交并结束本周。看中单小结，再到订单页查看采购和回款。
2. `npm run check` 覆盖到期交付与回款、迟交罚款及取消、库存、坏账追回、授信用尽、预测一致性和 52 周年度结算。
3. `V38_BROWSER=1 node --test tests/browser.test.mjs` 用 Chromium 在 1440px 桌面与 390×844 手机视口操作完整教程并报价，访问五页；用银行借款的浏览器测试推进至第 52 周年度结算，并继续进入第 53 周。
