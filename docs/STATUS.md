# 当前开发状态

更新：2026-11-11。v0.1 可恢复检查点。

## 已实现

- 三类五金询盘、三种谈判策略、三家工厂、三种出运方案。
- 员工提成与日薪，创业垫资与利润回款，取消订单资金返还。
- 业务员 → 创业 → 公司建设 → 阶段结局的经营路线。
- 简化仓储、物流与员工专长；现金紧张时可接不需垫资的小额代办，避免经济死局。
- 结算展示方案、品质和交期的口碑分项；未验货的新厂瑕疵扣 1 点品质口碑，验货或质检员工可避免。
- 五位角色各三段聊天场景，每段有两种回应及不同答复；退出对话不消耗晚间机会，不用选择隐藏的好感最优答案。
- 三名同事、一位总经理、一位老板，成年人；男/女主角均可玩。
- 异性约会明确确认、可保持朋友或结束关系、可不恋爱通关。
- 直接上下级在离职交接前只走职业关系；招聘不看恋爱状态，管理层可以拒绝加入。
- 浏览器自动保存、导出、导入和版本/结构校验。
- 响应式界面、键盘焦点、减少动态效果支持。
- 港口工作室场景、周屿与林知夏的首批原创生成插画已接入；统一美术方向见 `docs/ART_DIRECTION.md`。

## 已验证

- JavaScript 语法检查通过。
- 22 项状态机测试全部通过，包括男女同等经营进度、无恋爱通关、反复点击保护、资金返还、招聘与恋爱解耦、畸形存档及连续 100 天模拟。
- 浏览器实际点击跑通开局、员工订单、聊天与自愿约会、创业、创业订单、物流建设、阶段结局及继续经营。
- 浏览器确认取消约会/创业不改进度，刷新保留进度，导出下载与导入确认后成功恢复。
- 390px 宽 iframe（含滚动条时内容宽 375px）实查工作台、人物与公司页，无横向溢出，首批图片均成功加载。
- 这不是完整跨浏览器/真机验收，也不是市场好玩程度验证。
