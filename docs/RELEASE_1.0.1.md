# 外贸达人养成记 · 向海而生

当前完整内容版本：**v1.0.1**。轻经营与自愿关系剧情的离线浏览器游戏。3种五金产品、9组轮换询盘、8个经营章节、2个事业结局、8位成年角色关系线、24段工作日常、双休日与46张插画。男女主经营能力相同，恋爱并非通关条件。

## 试玩与交付

无需账户、后台、付费API或真实支付。源码运行需要 Node.js 20+，无需 npm install：

```sh
npm start
# 浏览器打开 http://127.0.0.1:4173
npm run check
npm run check:release-art
npm run build
```

构建输出：`artifacts/standalone-v101/外贸达人养成记-v1.0.1.html`。此HTML已内嵌46张图片，无外部网络资源依赖。将HTML和启动/发行说明一起交付；用户用支持JavaScript的现代浏览器打开。源码不是APK、iOS应用或小程序。

## 存档与升级

进度只保存在当前浏览器，不上传服务器。手账支持JSON导出、导入。换设备、浏览器、文件路径、升级版本或清理浏览器前先导出，并另存一份备份。导入前核对预览，确认会替换当前进度；不要用无痕模式保存长期进度。旧存档迁移由游戏校验完成，不要手改JSON。更新前保留旧HTML和存档，出现问题可回退。
