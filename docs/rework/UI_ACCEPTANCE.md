## 对朋友原话逐条落实

1. 布局不紧凑：缩减侧栏与无效留白，保留订单金额、利润、交期和报价入口的对照；手机不以隐藏利润换紧凑。
2. 废话与说明书在前台：删除装饰性长说明，保留影响玩家决策的费用、账期、风险和存档保护提示。
3. 开发语言露出：检查开局、四页、报价、升级、借还款、导入与错误、结局。文件格式技术名不当玩家指引；代码内 JSON 等实现不属于界面文案，不机械删除。
4. 数据流、曲线、货品价格：保留六品类行情、现金预测、签约锁价、成本与到账拆分；曲线不能只作装饰。
5. 不要对话式人物养成：本轮不恢复 NPC 对话、恋爱和人物养成，不增加“小满”等默认角色。
6. 清晰循环和正反馈：看询盘、算成本、签约履约、交付利润、分期回款、能力升级。收益与现金区别不得为视觉效果混淆。
7. 不要同质 AI 风格：原创港口调度/货运单据视觉，不抄参考代码或素材；不用无意义卡片数量冒充完成度。
8. 参考《基建狂魔》：借鉴同屏比较、资金预测和阶段目标，不照搬其过密手机排版或无关系统。
