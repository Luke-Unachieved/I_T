## 核心循环

看采购行情 → 比较询盘 → 调报价/工厂/运输 → 检查现金低点 → 签约锁价 → 逐周履约 → 分期回款 → 升级能力与进入新市场。

- 六种货品、三类客户订单：高定金快回款、低定金高利润长账期、紧交期补货。
- 签约付采购首款，生产完成付工厂尾款和运费，交付后按客户账期收剩余货款。钱与利润不混为一谈。
- 并行名额有限，订单交付才释放。长账期订单交付后不再占用名额，但尾款仍未到账。
- 报价升高影响成交率；客户拒单不扣钱。交期或品质不符的赔付在提交前显示，不事后突袭玩家。
- 已签采购价锁定，行情变化只影响下一单。现金图与明细含已有合同及公司支出，不含未来未签新单。
- 团队、验货、航线和集采改变后续接单能力，也产生持续运营成本。
- 交付记录解锁市场与复购加价；终章要求实际交付覆盖三大市场、净值 60,000，并合格交付欧洲年度框架试单（品质95、3周交付、15%订金）。不再用16单凑次数。达成后可继续。
- 单证代办与明示借款是恢复渠道，借款要付息，不是真实金融服务。

## 不承诺的东西

- 这是游戏化数值，不是外贸财务预测软件。六周预测不覆盖所有最长账期，也不证明永无资金压力。
- 本次没有真人玩家访谈，也不能把模拟体验家的评价称为真实市场验证。
- 尚未通过四画像实际 UI 通关、移动 Safari 真机、上架合规验收之前，不称可售成品。
- 不增加账号、后台、真实支付、AI API 或外部字体依赖。

### 第一轮真实体验反馈已吸收

经营型第21周16单、净值81,029通关冻结候选，但第16周现金与市场已满足，后六单只是补计数。因此第二轮候选将最终条件换为欧洲框架试单，要求先留产能、升级验货并准备低订金的大单周转。修复复购提价浮点显示长尾，新增交付利润回执。未发布的旧候选存档会保留旧阶段成就到 previousEnding，不丢资金/合同/客户；新终章等待框架挑战。

### 第三轮财务口径与验收

挑剔评审指出净值把尚未交付的预计利润提前入账。已改为：现金 − 借款 + 已交付应收 + 在途已付采购/运费 − 在途订金。交付时才确认利润。`ruleset:3` 保留旧测试候选成就到 `previousEnding`，资金/在途合同/合格试单进度不丢；旧预估利润达标但新实际净值未达标时，不冒充新版完成。

成长型同档回归第17周10单、实际净值63,359，合格框架试单及三市场履约、新终章、刷新保存均过。原第16周旧口径通关不计为最终证据。收货回执改「结算时现金变化」，不误导为接新单/升级后的整周净变化；终章补周数、交付、净值成绩卡。自动检查261项通过。
