## 可继承的判断标准，而非照搬旧版机制
1. 选择应真正改变结果：不是每次点最高利润，也不是靠隐藏随机拒单制造深度。
2. 升级要改变能做什么或享受什么，而非纯堆金额/倍率。
3. 成长来自做成具体客户合作；不靠重复刷交付次数凑终点。
4. 交货、利润与现金到账不混淆，且界面要让玩家看懂。
5. 本局回顾应来自真实成果，不是泛化成功鸡汤。
6. 不用为“完整版”硬造无限数值循环；长期是否好玩须单独验证。

| P1 | 买书/双面唱片原先只出现按钮而没有场景物件 | 已补实物与直接使用；最终复合画面待验收 |
| P1 | 多个业务机会与当前合作争注意力、内部解释文案外露 | 已实现当前合作置前与次要入口收纳、展示文案映射；可发现性待验收 |
| P1 | 签约/交货/回款动作过于抽象 | 已加短图形动作，并区分交货与到账；不等于最终美术质量通过 |
| P1 | 缺少可追溯的大锐/参考项目原材料，无法核实是否采纳 | 协调线程恢复来源；不以旧AI评审冒充大锐意见 |
| P2 | 新增物件、动作和文字仍需手机构图/节奏及真人反馈 | 纳入最终体验检查，不凭静态代码下好玩结论 |
