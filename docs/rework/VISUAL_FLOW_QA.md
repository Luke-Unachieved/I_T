# 经营可视化第一批（2026-11-14）

本次按用户“可视化程度越高越好”方向，仅修改现行数据版展示，不修改经济、存档格式、旧版或生活玩法。

- 经营页显示国内集货港到三大市场的业务示意，未解锁、空闲、运输中区分；各条线路显示实际在途合同数量，非虚构实时船位。
- 生产备货、出口运输、等待尾款三组数量及履约名额直接取当前经营状态。
- 每单增加签约、出运、交付、尾款四阶段时间轴；按实际出运付款标志切换阶段，缺资金的订单不能仅凭日期假装已出运。

- 不添加后台定时推进，日期仍由玩家操作；生活入口仍在内容底部右边。
