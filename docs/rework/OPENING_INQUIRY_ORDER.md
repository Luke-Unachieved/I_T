# 开场询盘：可以暂缓，日期不会等人

首次进游戏仍是 Mira 的台灯询盘，无需打开新菜单。未签时可选择“暂缓这封，看看其他询盘”，对比客户的实际货款、先垫金额、交货与收齐日，再回到实物和报价。浏览、切换、收起都不花钱、不走日期，也不制造合同。不提供免费补贴、延期特权或虚构行情。

Samir 的现货能否赶上第7天开业、Inês 的季度单能否赶上第11天陈列，仍按实际时钟核价。例如同样接三份「台灯铺货、杯现货、桌布季度」：先灯→杯→布，第26天现金7850；改为杯→布→灯，第23天现金9040。差异来自原有时窗和合同周期。换序不是永久删掉一位客户；三位都实际收齐后才开放原有引荐/生活入口，已完成的客户不再次出现为首访。

只有在向另一位客户正式提案时才产生新动作。签后不可切换该合同，预付试探被拒绝不扣款/不记成交。恢复进度以后，未签的临时浏览不保留；已经提交的报价、成交与回款按原纪录继续。没有迁移或放宽旧档验证。

开发验证：6种客户顺序×8种合同组合逐步回放；传统8条终态序列化 SHA-256 与 d6ac55f 的原引擎相同。测试还覆盖拒绝、切换、资金/日期、付款前不可引荐、实际引荐数量、旧/新备份与非法篡改，以及离线整包在 Node 模拟 DOM 中的事件绑定。此为规则与自动验证，不是 Windows 整机游玩、手机排版或真人体验验收。
