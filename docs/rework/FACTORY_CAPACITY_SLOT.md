# 恒序暖光灯：量产客户结清后的机时谈判

沿用原策划“选工厂、谈交期”和“后期做经营判断而不是反复跟单”，而非新增与外贸无关的支线。Mira 真实结清恒序 180 盏暖光灯后，工厂提供一次机时空档，第一或第二工厂路径都可出现。四个游戏日是含预订当日在内的四日，必须在窗口内签下一笔同厂同款 180 盏合同；不是强制下单，也不会重写先前交期。

可完全不订，标准排期仍五天；预订立即支出 ¥90，即使没用也不退。使用才缩至三天生产，仍需原采购款、按原 30% 定金和交货后七天的账期收尾款。因此本单若只看净额，少两天日费 ¥60 并不足抵预约费，最后现金比常规少 ¥30；玩家换来两天时间而非自动获利。使用后或过期后都恢复标准排期，不从其他订单、投资或现金不足路径产生补贴。属于游戏内虚构业务条件。

当门店库存管理已开启，工厂与客户的日历一起核对：当前四日窗口早于 Mira 售罄日时，显示门店余量和最早可再询问的日期，不收订档费。若窗口仅最后一天与买方需求相交，也会提前说明。此前版本已支付并记录的历史预订照原样恢复，不暗中退款或移走合同。
