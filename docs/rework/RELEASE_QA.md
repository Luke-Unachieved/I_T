## 已吸收的问题

- 后半段只刷16单：换成有能力、交期、低订金要求的欧洲框架试单。
- 净值提前记利润：按已付成本/已交付应收入账，交付才确认利润。
- 复购百分比浮点长尾、并行容量误称在途、现金回执时点歧义：均修复。
- 框架不合格方案：明确提示不能完成最终目标，而不只显示赔付。
- 终章收尾泛泛：增加周数/交付/实际净值成绩卡。
- 手机报价过长、小按钮换行、行情小字：压缩双列、折叠明细与外置时间标签。
