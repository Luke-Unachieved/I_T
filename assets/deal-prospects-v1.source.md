# 百位潜客·人物名片图集（2026-11-19 重建版）
 
**用途与来源。** 本次重建的新角色肖像，不是找回的旧版百人原画，也不是真人照片。插画使用 OpenAI 图像生成工具为本项目制作：七组正方形 5×5 水粉和彩铅人物研究，一幅按可见外貌特征重绘的 Joon Lim 单人研究。为当代经营者设置了不同年龄段、发型、五官、服饰、姿态、表情、配件与纸色。按新版名册从不同画板挑选、裁齐、排版为 100 张不复用的肖像；未在库中找到可确认的旧版完整原图集。给旧图库取名与角色编号不是历史复原。没有用其他游戏的武侠头像、共享的典型脸、姓名缩写，或历史截图像素充数。

**个案史料。** 2026-11-19 的存档画面《01-客户首单事件.jpg》和《02-选择让价及客户回话.jpg》用于核对可见参考；前者出现「Joon Lim·釜山·红珊夜宵」与其戴眼镜、蓄小胡须、穿深色外套的头像。没有给出该角色的历史 ID。现行编号 008，按视觉参考另画，未将截图裁成这个头像。

**交付文件。**
- `deal-prospects-v1.source.webp`：最终配对和裁剪后的无损母版。2000×2000、无边框/文字/留缝的 10×10 方格，每人 200×200。
- `deal-prospects-v1.webp`：实际游戏文件。每格独立用 Lanczos 缩至 160×160，再按相同顺序拼成 1600×1600；WebP quality=82，method=6；577,854 字节。源母版不作为玩家下载资产嵌入离线版。
- 母版从左到右、从上到下对应 `001...100`。角色 008 单独重绘。后续替换单张时先改母版同格、保持 ID 和自然比例，再生成游戏版；不要移动名次造成旧存档换脸。网页 resolver 对未知 ID 输出空串，对有效 ID 只使用固定资源和数值，临近文字负责报出人物身份。

**验证边界。** 自动验证母版与运行版可解码、各 100 个单元的解码像素摘要互异，ID 坐标、异常输入、资源字节长度、尺寸及校验和均记录。AI 查看了原始画板和最终整体联络表，不等同于真人美术审稿、100 位真实玩家意见或所有界面整机验收。专项测试：`node --test tests/deal-prospect-avatar.test.mjs`。
