# 再开一单就下班

现代外贸工作室经营游戏：从客户询盘、样品和报价起步，谈交期与付款，发展已交付的客户合作、商品和设计范围。

> **当前开发方向：现代外贸工作室。** 默认构建已切到现代开发候选，不代表完整版已完成、目标设备全验或商店审核通过。原正式网站、旧入口与旧存档保留；本次构建入口调整不会自动发布网站。

## 从源码运行现代候选

需要 Node.js 20+，没有第三方运行依赖，无需 npm install。

```sh
npm start
# 打开 http://127.0.0.1:4173/deal-room.html
npm run build
npm run check
```

现代源码入口是 `deal-room.html`，界面为 `src/deal-room-app.js`，核心规则为 `src/deal-room-engine.js`，各专题由同前缀模块组织。本地 `npm start` 的根路径 `/` 现在打开现代 `deal-room.html`；仓库 `index.html` 及既有托管站点仍保留 legacy 旧入口，未随本地调整发布。验收现代候选请核对实际打开的是工作室，而不是旧港口画面。

## 默认构建与交付身份

`npm run build` 等同于 `npm run build:modern`，运行 `scripts/build-deal-standalone.mjs`，输出到 `artifacts/deal-room/`：

- `再开一单就下班-开发候选.html`：图片、样式与脚本内联的现代单文件入口。
- `版本信息.json`：本次内容编号、SHA256、字节数、存档键与候选标识。
- `先读我.txt`：打开、保存与恢复说明。

打开上述 HTML，不是 `artifacts/data-v2/index.html`。按本次清单核对文件，不沿用历史哈希。构建不会压缩、上传、切换正式站或自动上架；待目标环境与发行条件确认后，才决定具体发布方式。不要把整个仓库、测试存档或其他历史包当作现代发行物上传。

`npm run check` 先检查现代关键入口语法，再保留历史语法及全部测试。`npm test` 的 `pretest` 显式构建现代和 legacy 测试依赖，保证旧回归仍能读取原产物；生成旧测试产物不表示旧版仍是默认交付。

# 《外贸大亨》初步策划案

我先构思了一版，《外贸大亨》可以做成 **经营模拟＋商战剧情**：

**开局是小业务员，被客户压价、被工厂催款、还要担心老板抢功；后来自己开公司、做品牌，最后成为能决定一笔大生意走向的商业大佬。**

最重要的是让它有外贸的味道，但玩起来不能像真的在加班。

**一、核心怎么玩**

找客户 → 谈报价 → 选工厂 → 打样和验货 → 安排出货 → 收款赚钱 → 扩大公司。

每张订单都不是简单点一下收钱，而是要做几个有意思的决定。比如：客户要压价，工厂报价低但质量不稳定，大客户又要求长账期。你可以让利争取长期合作，也可以坚持价格，甚至放弃订单。

重复性工作可以交给员工或自动处理，玩家主要负责谈判、选人和做决定。

**二、从业务员到大亨**

1. **外贸新人**：在小公司接询盘、跟样品、争取第一笔订单。赚工资和提成，积累客户与经验。
2. **独立创业**：开工作室，自己承担垫资和回款风险，招第一个员工。
3. **公司老板**：成立销售、采购、质检团队，参加展会，拓展海外市场。
4. **行业大佬**：建立品牌、海外仓或供应链，和大型集团谈合作、收购或竞争。

不一定只有“公司越大越好”一种赢法。做一家利润高、客户稳定的精品公司，也可以成为成功结局。

**三、霸道总裁元素怎么加**

我觉得可以让玩家前期遇到一位强势的集团负责人：有钱、有资源、谈判气场很足，但也有自己的商业目的。

比如他看中了你的能力，给你一笔能改变命运的大订单，却要求你只能给他的集团供货。你可以接受、拒绝，或者反过来谈条件。之后他既可能是合作伙伴，也可能变成竞争对手。

剧情里可以有暧昧和感情线，但让玩家自己决定要不要发展；不谈恋爱也能正常做生意。最爽的一条成长线是：**一开始你去求他签合同，后来轮到他来争取和你合作。**

**四、一个有外贸味道的例子**

你拿到一笔五金订单，账面看能赚 2,500 美元，但客户定金不够付工厂，出货前还差 3,100 美元。

这时可以选择：
- 找客户提高定金，可能影响成交。
- 找工厂谈账期，需要信誉和关系。
- 借钱垫资，利润会被利息吃掉一部分。
- 接受总裁投资，但可能要让出股份或独家权。
- 放弃大单，先做回款更快的小单。

这样就能把外贸里的现金流、谈判和霸总剧情自然结合起来。

**五、我建议的首个可玩版本**

先从五金贸易切入，做几种产品、几家工厂和不同类型的客户，再加一条总裁剧情线。先把“找客户、接单、赚钱、创业”的完整流程做有趣，之后再逐步扩展到其他行业和海外市场。

这是初步方向，平台和美术形式还没定。我觉得可以先讨论一个关键选择：你想要的霸总元素，是**玩家自己逐渐成为霸总**，还是**游戏里有霸总人物和玩家发生剧情**，或者两者都要？
