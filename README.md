# 再开一单就下班

以报价、履约、现金流和市场扩张为核心的轻量外贸经营游戏。

[开始游戏](https://luke-unachieved.github.io/I_T/)

> 当前修订合并重复的推进提示，并让新市场解锁提示与询盘实际到达时间一致。

## 怎么玩

看商品行情 → 接海外询盘 → 选供应商、运输与报价 → 安排交付 → 收回尾款 → 扩大公司与市场。

- 默认推进一天，也可快进 3 天或 7 天；重要机会和资金不足会暂停。
- 美元报价、人民币采购；尾款可选择付费锁汇或到期浮动结汇。
- 付款方案只需三选：原条件、让价早回款、给账期换高价。
- 图表展示现金、商品价格与已签订单收付，玩家不需要填写复杂报表。

## 本地运行与构建

需要 Node.js 20+，无需安装依赖。

```sh
npm start
# http://127.0.0.1:4173
npm run build
npm run check # 先 build：部分验收读取构建产物
```

现行网页构建在 `artifacts/data-v2/`，主入口为 `index.html`。发布时使用该目录完整内容，不能将源码目录或测试存档当成发行包。构建也携带 `classic.html`，仅为已有旧链接和旧存档保留兼容，不作为现行游戏模式推广。原剧情源码不再扩展，但不在此次修订中永久删除。

# 《外贸大亨》初步策划案

我先构思了一版，《外贸大亨》可以做成 **经营模拟＋商战剧情**：

**开局是小业务员，被客户压价、被工厂催款、还要担心老板抢功；后来自己开公司、做品牌，最后成为能决定一笔大生意走向的商业大佬。**

最重要的是让它有外贸的味道，但玩起来不能像真的在加班。

**一、核心怎么玩**

找客户 → 谈报价 → 选工厂 → 打样和验货 → 安排出货 → 收款赚钱 → 扩大公司。

每张订单都不是简单点一下收钱，而是要做几个有意思的决定。比如：客户要压价，工厂报价低但质量不稳定，大客户又要求长账期。你可以让利争取长期合作，也可以坚持价格，甚至放弃订单。

重复性工作可以交给员工或自动处理，玩家主要负责谈判、选人和做决定。

**二、从业务员到大亨**

1. **外贸新人**：在小公司接询盘、跟样品、争取第一笔订单。赚工资和提成，积累客户与经验。
2. **独立创业**：开工作室，自己承担垫资和回款风险，招第一个员工。
3. **公司老板**：成立销售、采购、质检团队，参加展会，拓展海外市场。
4. **行业大佬**：建立品牌、海外仓或供应链，和大型集团谈合作、收购或竞争。

不一定只有“公司越大越好”一种赢法。做一家利润高、客户稳定的精品公司，也可以成为成功结局。

**三、霸道总裁元素怎么加**

我觉得可以让玩家前期遇到一位强势的集团负责人：有钱、有资源、谈判气场很足，但也有自己的商业目的。

比如他看中了你的能力，给你一笔能改变命运的大订单，却要求你只能给他的集团供货。你可以接受、拒绝，或者反过来谈条件。之后他既可能是合作伙伴，也可能变成竞争对手。

剧情里可以有暧昧和感情线，但让玩家自己决定要不要发展；不谈恋爱也能正常做生意。最爽的一条成长线是：**一开始你去求他签合同，后来轮到他来争取和你合作。**

**四、一个有外贸味道的例子**

你拿到一笔五金订单，账面看能赚 2,500 美元，但客户定金不够付工厂，出货前还差 3,100 美元。

这时可以选择：
- 找客户提高定金，可能影响成交。
- 找工厂谈账期，需要信誉和关系。
- 借钱垫资，利润会被利息吃掉一部分。
- 接受总裁投资，但可能要让出股份或独家权。
- 放弃大单，先做回款更快的小单。

这样就能把外贸里的现金流、谈判和霸总剧情自然结合起来。

**五、我建议的首个可玩版本**

先从五金贸易切入，做几种产品、几家工厂和不同类型的客户，再加一条总裁剧情线。先把“找客户、接单、赚钱、创业”的完整流程做有趣，之后再逐步扩展到其他行业和海外市场。

这是初步方向，平台和美术形式还没定。我觉得可以先讨论一个关键选择：你想要的霸总元素，是**玩家自己逐渐成为霸总**，还是**游戏里有霸总人物和玩家发生剧情**，或者两者都要？
